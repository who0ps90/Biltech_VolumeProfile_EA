3. PROFILE CALCULATION
==================================================

Defaults:
- RequestedRows = 60.
- ValueAreaPercent = 70.
- Use only the previous completed valid reference session.

Define bins deterministically:
- Align lower boundary downward to trade tick size.
- Choose a bin width that is an integer multiple of tick size and
  covers the observed range within the requested row count.
- Document actual row count and any rounding.
- Include the maximum observed price in the final bin.

POC:
- Bin with the greatest weight.
- On ties, choose the bin closest to the profile midpoint.
- If still tied, choose the lower bin.
- POC price = midpoint of the selected bin.

Value area:
- Start with the POC bin.
- Compare the immediately adjacent unused bins above and below.
- Add the higher-weight bin and repeat until accumulated weight
  reaches or exceeds the selected percentage.
- On ties, add the lower bin first.
- VAH = upper edge of the highest included bin.
- VAL = lower edge of the lowest included bin.

This deterministic algorithm need not match TradingView exactly.
Explain differences rather than claiming equivalence.

Freeze POC, VAH, and VAL once the session completes.
Never use current-session future data or rebuild historical signals
with information unavailable when they occurred.

Store previous reference-session close using the same price convention.
Define "inside value" as VAL <= close <= VAH.

6. SETUP A: VALUE-AREA RE-ENTRY
==================================================

Enabled by default.

Eligibility:
Previous reference session closed inside its value area.

LONG:
1. A completed M5 bar closes below frozen VAL.
2. Start an excursion state.
3. Within the next 3 completed bars, a candle closes strictly above
   VAL and below VAH.
4. That close confirms re-entry.
5. Enter buy on the next eligible tick.
6. Stop below the lowest low from the initial excursion bar through
   the confirmation bar, minus Buffer.
7. Target = actual entry + 2 × initial stop distance.

SHORT:
Mirror above:
- Initial close above VAH.
- Re-entry close strictly inside value.
- Stop above excursion high plus Buffer.
- Target 2R below entry.

Expire excursion after 3 confirmation opportunities.
Do not restart its timer on each additional outside close.
Require a new completed inside-value bar before rearming an expired
excursion in that direction.

Default space filter:
- Long: previous POC must be at or beyond the proposed target.
- Short: previous POC must be at or beyond the proposed target
  in the short direction.
- Skip if entry has already passed POC.

Make the space filter configurable.
Log its effect separately in results.

==================================================
7. SETUP B: BREAKOUT CONTINUATION
==================================================

Implemented but disabled by default.

Previous session may close inside or outside value.

LONG:
1. A completed bar closes above VAH + Buffer, after the preceding
   completed bar closed at or below that threshold.
2. Freeze breakout-bar high, ATR, and Buffer.
3. Within the next 6 bars, a later bar touches the band
   [VAH - Buffer, VAH + Buffer] and closes above VAH.
4. That is the retest bar.
5. Within the next 3 bars after the retest, a later candle closes
   above the maximum of breakout-bar high and retest-bar high.
6. Enter on the next eligible tick.
7. Stop below the lowest low from retest through confirmation,
   minus frozen Buffer.
8. Target 2R.

Invalidate if any bar before entry closes below VAH - Buffer.
Expire states at their specified limits.

SHORT:
Mirror all rules at VAL.

Require breakout, retest, and confirmation on separate bars.
Do not use hindsight swing points or unconfirmed fractals.

==================================================
8. SETUP C: POC BOUNCE
==================================================

Implemented but disabled by default.

LONG eligibility:
Previous reference session closed above VAH.

LONG:
1. Previous completed candle closed above POC + Buffer.
2. The next candle touches the POC buffer band.
3. That candle closes above POC + Buffer and is bullish.
4. Enter on the next eligible tick.
5. Stop below the signal candle low minus Buffer.
6. Target 2R.

SHORT eligibility:
Previous reference session closed below VAL.

SHORT:
Mirror the long rules, with approach from below and bearish rejection.

Reject if the signal candle closes through the far side of the POC band.
Document that these candle definitions are an operational research
interpretation, not independently verified original-video rules.
